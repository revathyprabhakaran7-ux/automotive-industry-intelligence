# Automotive Sales Forecasting

## Overview

This project explores forecasting methods for Canadian automotive sales using historical industry data.

The goal is to understand sales patterns, compare forecasting approaches, and evaluate how predictive analytics can support business planning.

## Data Source

[Statistics Canada — New Motor Vehicle Sales, Monthly](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=2010008501)

## Tools and Technologies

Python · pandas · NumPy · scikit-learn · MLflow

## Project Scope

- Prepare and explore historical automotive sales data.
- Analyze trends and seasonality.
- Develop baseline and machine learning forecasting models.
- Evaluate model accuracy using appropriate metrics.
- Document findings and limitations.
