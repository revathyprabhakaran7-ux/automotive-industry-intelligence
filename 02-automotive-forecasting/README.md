# Automotive Sales Forecasting

## Overview

Forecasting Canadian new motor vehicle sales using historical monthly data from Statistics Canada.

The project compares a seasonal baseline with Ridge regression to assess forecasting accuracy and generate a 12-month sales forecast.

## Data Source

[Statistics Canada — Table 20-10-0085-01: New Motor Vehicle Sales](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=2010008501)

Monthly vehicle sales data covering January 1946 to August 2026.

The forecasting script uses the cleaned dataset generated by Project 1.

## Tools and Technologies

Python · pandas · NumPy · scikit-learn · MLflow · GitHub Actions

## Methodology

- Prepare historical monthly vehicle sales data.
- Create lag features using previous sales observations.
- Include rolling averages and seasonal indicators.
- Train a Ridge regression model.
- Compare predictions against a seasonal naïve baseline.
- Evaluate both methods using a 24-month holdout period.
- Select the model with the lowest mean absolute error (MAE).
- Generate forecasts for the following 12 months.

## Model Evaluation

**Holdout period:** September 2024 – August 2026

| Metric | Seasonal Baseline | Ridge Regression |
|---|---:|---:|
| MAE | 8,532.83 | 7,607.53 |
| RMSE | 10,073.38 | 9,826.17 |
| MAPE | 5.20% | 4.73% |

Ridge regression achieved approximately 10.8% lower MAE than the seasonal baseline.

The evaluation uses one-step-ahead predictions with observed historical values. The subsequent 12-month forecast is generated recursively, so its accuracy is not established by these holdout metrics.

## Outputs

- `holdout_predictions.csv` — Actual sales and model predictions for the evaluation period.
- `forecast_12_months.csv` — Forecasted monthly sales.
- `evaluation_metrics.json` — Model comparison and evaluation results.

## Automation

GitHub Actions installs the required dependencies, prepares the source data, executes the forecasting script, and runs automated checks.

## Limitations

Forecast accuracy may be affected by changes in consumer demand, economic conditions, vehicle supply, and other market factors.

The forecasts are statistical estimates and are not official Statistics Canada projections.
