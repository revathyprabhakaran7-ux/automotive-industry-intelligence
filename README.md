# Automotive Industry Intelligence

A portfolio of projects exploring how business intelligence, predictive analytics, and artificial intelligence can support decision-making in the automotive industry.

The focus is on transforming publicly available industry data into meaningful insights through data analysis, visualization, forecasting, and AI-driven tools.

## Projects

### 01 — Automotive Business Intelligence

An analysis of automotive market performance, sales trends, and regional differences using SQL, Python, Power BI, and Excel.

The project focuses on data preparation, KPI development, interactive dashboards, and communicating insights relevant to business operations.

### 02 — Automotive Sales Forecasting

A predictive analytics project exploring historical vehicle sales patterns and forecasting future trends.

The work includes exploratory data analysis, time-series forecasting, model comparison, and performance evaluation using Python, scikit-learn, and MLflow.

### 03 — Automotive AI Analytics Assistant

A planned AI application designed to support natural-language exploration of automotive industry data.

The project will explore generative AI, prompt engineering, tool calling, AI agents, and Model Context Protocol (MCP) to retrieve and interpret analytical results.

## Technologies

**Data Analysis and BI:** SQL, Python, pandas, NumPy, Power BI, Excel

**Machine Learning:** scikit-learn, time-series forecasting, MLflow, model evaluation

**Generative AI:** Large language models, prompt engineering, tool calling, AI agents, MCP

**Development and Automation:** Git, GitHub, GitHub Actions, automated testing, CI/CD

**Project Management:** Agile/Scrum practices, Jira, technical documentation

## Data Sources

The projects will use publicly available automotive industry datasets, including information published by Statistics Canada and other official government sources.

Each project will document its specific data sources, preparation methods, assumptions, and limitations.

## Development Approach

The projects will follow an iterative development process, beginning with data exploration and business requirements, followed by implementation, testing, evaluation, and documentation.

GitHub will be used for version control, while automated workflows and project-tracking practices will be introduced as development progresses.

## Project Status

**In development**

Source code, datasets or retrieval instructions, dashboards, model evaluation results, and technical documentation will be added as the projects are completed.
